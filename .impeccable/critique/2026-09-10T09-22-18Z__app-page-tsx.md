# Overall Impression

The site's writing is confident and specific; its screen is not finished. The two moments a skeptical buyer needs the most — "show me the product" and "tell me the price" — are both currently placeholders rendering on the live page, one of them literally showing an internal admin instruction ("SUBSTITUIR") to real visitors.

- **The poster-close section** (`bg-marca text-acao-tx`) — the one deliberate full-bleed use of the brand color, exactly the restraint DESIGN.md's "one accent color" rule calls for, actually followed rather than just declared.
- **"Sigilo auditável" feature row** — turns a compliance requirement (masking, logged "Revelar" reason, scoped support access) into a concrete, hard-to-copy selling point, exactly matching PRODUCT.md's stated positioning.

# Priority Issues

**[P0] Live pricing section shows an internal admin instruction to real visitors.**
Why it matters: All 4 named plans render `R$ —/mês` in a dashed box tagged "Substituir" — Portuguese for "Replace", an admin todo — live-verified on the rendered page, not just in source. Pricing is the #1 trust checkpoint for a skeptical buyer; this reads as a bug.
Fix: When a plan's modules have no price configured, hide the card or show neutral customer copy ("Fale com a gente para o valor deste plano") instead of the dashed box + admin tag.
Suggested command: `$impeccable harden`

**[P0] All 5 feature rows substitute a caption for a real screenshot.**
Why it matters: `Captura de tela — {description}` renders literally in a bordered box for every one of the 5 feature rows — 100% of the "here's the product" section is text-about-an-image. A first-time buyer needs to see the product to build trust before handing over case/financial data.
Fix: Until real photography exists, replace the caption boxes with an intentional branded diagram/illustration system in the ruled/bordô visual language — a designed placeholder, not a developer placeholder.
Suggested command: `$impeccable adapt`

**[P1] Mobile users lose the header nav entirely.**
Why it matters: `<nav className="hidden md:flex">` hides Produto/Preço/Blog/Entrar below `md` with no hamburger or alternate control — only logo and "Começar" survive on phone.
Fix: Add a minimal mobile menu (Menu/X icon toggling an overlay) reusing the same left-aligned, ruled-divider language as the rest of the system.
Suggested command: `$impeccable layout`

**[P2] Pricing decision point exceeds the 4-choice cognitive-load guideline with no guidance.**
Why it matters: 5 simultaneous plan cards, no "recomendado" anchor, 4 of 5 with no price to differentiate on — the highest-friction moment on the page.
Fix: Give one plan a visually distinguished "recomendado" treatment using the existing `acao-light` token (already reserved in DESIGN.md for branded secondary emphasis).
Suggested command: `$impeccable clarify`

**[P3] `vinho` (destructive-only token) reused for a non-destructive "price pending" state.**
Why it matters: `placeholderBox`/`placeholderTag` resolve to `--vinho` (#ae1800), the token DESIGN.md reserves exclusively for irreversible destructive actions. This is a second, uncontrolled accent color on the site's most scrutinized section.
Fix: Give "price not yet configured" a neutral treatment (`--regua-forte` border, no accent color) instead of the destructive-action red.
Suggested command: `$impeccable colorize`

# Minor Observations

- `app/page.tsx` comment claims the accent is "vermelho #ec3013," but tokens already migrated to bordô `#8a2f42` — comment rot, not user-visible.
- Footer "Produto" column omits the Blog link present in the header nav.
- `text-tx-3` (#9b9797) against white/`#f3f2f2` measures ~2.6–2.9:1, well under WCAG AA's 4.5:1 — worth auditing since PRODUCT.md notes no formal accessibility standard is set yet.
- H1 is capped at `max-w-[15ch]`, forcing a 3-line wrap — check at 900–1100px viewports where clamp() and the char cap can interact awkwardly.
- The blog's Lora-serif exception is a well-reasoned, documented voice split, but isn't extended anywhere else (e.g. homepage blockquotes still use Inter).
